# Rubain Kharchane — Portfolio

A responsive personal portfolio website introducing Rubain Kharchane, an aspiring software engineer and full-stack developer.

## About the site

The single-page portfolio includes:

- An introduction with links to the résumé and contact section
- About, skills, featured projects, certifications, education, and contact sections
- Responsive navigation and scroll-based animations
- A downloadable résumé PDF

## Project files

| File | Description |
| --- | --- |
| `index.html` | Portfolio content and page structure |
| `style.css` | Layout, styling, and responsive behavior |
| `script.js` | Navigation interactions, smooth scrolling, and animations |
| `Rubain_Kharchane_Resume.pdf` | Résumé linked from the page |

## Run locally

No build step or package installation is required. Open `index.html` in a browser, or serve the project directory with a local web server. For example, if Python is installed:

```sh
python -m http.server 8000
```

Then visit <http://localhost:8000>.

The page loads Google Fonts, Font Awesome, and GSAP from external CDNs, so an internet connection is needed for those resources.
